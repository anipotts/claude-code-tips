# code of conduct

## purpose

coding agent tips is a professional engineering publication. participation should
help readers inspect claims, reproduce results, and improve consequential software
work.

## expected conduct

- discuss technical decisions with specific evidence and respect.
- give feedback on the work without attacking the person behind it.
- protect credentials, private transcripts, personal data, and unpublished reports.
- accept corrections openly and acknowledge the people who contributed them.

## unacceptable conduct

- harassment, threats, discriminatory language, or unwanted sexual attention.
- insults, sustained disruption, intimidation, or personal and political attacks.
- publishing another person's private information without explicit permission.
- using project spaces to promote scams, spam, referral schemes, or unrelated work.

## scope

this policy applies to repository issues, pull requests, discussions, reviews, and
other spaces where someone represents this project.

## reporting

report conduct concerns privately to `hello@anipotts.com`. include the relevant
links, dates, and context so the report can be reviewed accurately. security
vulnerabilities follow [SECURITY.md](./SECURITY.md).

if a report concerns the maintainer or requires immediate platform action, use
[github's report abuse process](https://support.github.com/contact/report-abuse).

## response

the maintainer will review available evidence, protect the reporter's privacy, and
choose a response proportionate to the behavior. possible responses include:

- a private clarification or request to correct the behavior.
- removal of comments, reviews, or other project content.
- temporary limits on participation in project spaces.
- permanent removal from project spaces or escalation to github.

the maintainer will disclose conflicts that affect a fair review and will preserve
the minimum record needed to explain an enforcement decision.
