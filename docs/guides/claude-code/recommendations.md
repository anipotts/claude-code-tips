## choose by the review loop

| if this sounds like you | begin here |
|---|---|
| you want a visible task and diff workflow | Claude Code on desktop |
| you already work through shell tools | the terminal with one repository and clear checks |
| your editor is your main context | the IDE integration with repository instructions checked in |
| you need to steer a host from elsewhere | remote control after reviewing its access boundaries |

use Cowork when the output is a broader deliverable or the task spans general
apps and documents. use Claude Code when the result belongs in a repository and
needs engineering review.

these are source based starting points. i will narrow them after a current
paired field run produces inspectable examples.
