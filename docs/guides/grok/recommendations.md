## begin with the product boundary

use Grok Build when the task belongs in a repository and a terminal based agent
loop makes sense. evaluate Grok Bot when the work needs a persistent cloud
computer, browser sessions, apps, and coordination across named agents.

start with a reversible task, narrow access, and a result you can inspect. the
official surface is moving quickly and my hands on evidence here is still thin.
more detailed recommendations will follow a public field run.
